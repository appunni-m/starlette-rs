# Security Policy

## Report a vulnerability

Please do not include suspected vulnerability details in a public issue,
discussion, or pull request.

If this repository offers GitHub's **Report a vulnerability** action in its
Security and Advisories area, use it to send the report privately to the
maintainers. GitHub only accepts private reports when the repository has
private vulnerability reporting enabled. See [GitHub's private reporting
guide](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).

If the private reporting action is unavailable, open an issue that asks only
for the preferred private security contact. Do not put technical details in
that issue. Share affected versions or commits, configuration, reproduction
steps, and impact only after a private channel has been established.

The maintainers will coordinate investigation, a fix, and disclosure with the
reporter. This project does not promise a fixed response or resolution time.
